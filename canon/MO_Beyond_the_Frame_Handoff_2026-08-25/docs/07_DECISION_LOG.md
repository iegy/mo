# Decision Log

This file records user-approved decisions to reduce future ambiguity.

## Core decisions

- The project is an interactive story site using colored comic/manga-style presentation.
- Mo moves inside the actual comic scene/section according to scroll and scene context.
- The first approved mockup exactly captured the desired direction: colors, illustration style, atmosphere, and concept.
- Site structure is chapters.
- Goal is entertainment stories, not portfolio/service marketing.
- Best possible visual experience is prioritized.

## Character/language decisions

- Mo does not speak.
- Site is Arabic + English.
- Arabic version uses Egyptian Arabic dialogue.
- Audience is all ages.
- Tone order is Comedy → Adventure → Mystery → Emotion → Action → Science Fiction.
- Each adventure is independent with a larger thread connecting them.
- Mo may gain a team later.
- Human characters can sometimes appear.
- Sad/emotional moments are allowed sometimes.

## Story/world decisions

- Do not confine the series to coding worlds.
- Use multiple different worlds while keeping the Frames/Margin meta-concept.
- Main mysterious long-term threat approved: **The Blank / الفراغ**.
- PIX is better as a different kind of creature, not another robot.
- Each chapter releases complete.
- Mo begins unaware of “outside the frame.”

## Interaction decisions

- Scroll-driven experience is primary.
- Optional taps/clicks and hidden interactions can enhance the experience.
- Soft choices may exist but should not explode into a full branching narrative.
- Chapter duration target: 10–15 minutes.

## Naming decisions

- Main character name officially locked: **Mo / مو**.
- Series working name: **MO — Beyond the Frame / مو — خارج الإطار**.
